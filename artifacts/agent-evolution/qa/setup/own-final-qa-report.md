QA замораживает и освобождает **СЕМЬ ВХОДНЫХ ФАЙЛОВ QA РАНТАЙМА**, идентифицированных семью фактическими SHA-256 в поле runtimeInputSHAs7 в [freeze receipt](</Users/princeofscale/Desktop/gym/tyaga-agent-evolution/artifacts/agent-evolution/qa/setup/own-final-freeze.json>). Вся имеющаяся доказательная база QA неизменяема.

Задача 3 (SETUP контур) полностью завершена. Инженер теперь должен самостоятельно выполнить следующие шаги **ТОЛЬКО ПОСЛЕ прямого распоряжения Лида**:
```bash
npx tsc --noEmit
npm test
npm run build
```

Скрипт `pretest` репозитория осуществляет сборку Worker; в контуре QA он намеренно не запускался на этапе заморозки.
Свежий запуск команды `npm test` неизбежно сгенерирует новые одноразовые артефакты миграций (`migration-*`) и локальные каталоги состояний D1 в результате выполнения неизменяемого теста миграций QA. **Это является разрешённым одноразовым выводом тестового прогона**, а не публикацией новых миграций, редактированием Drizzle или удалённой мутацией.
Заморозка относится строго к входным файлам и зафиксированным историческим прогонам, а не к запрету генерации свежих тестовых артефактов при будущих запусках.

Повторная QA/runtime-верификация требуется при изменении существующих кодовых/SQL/runtime INPUTS. Обновление документации/receipt SHA, новые логи, свежие migration-* фикстуры и разрешённая production dist-сборка из неизменённых inputs сами по себе не переоткрывают QA. Root обязательный протокол принадлежит Engineer после Lead GO; фактическое изменение runtime inputs требует отдельной reverification существующего стенда, не замещающего сервера.
