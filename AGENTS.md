# AGENTS.md — Руководство для AI-агентов и разработчиков

Данный документ содержит стандарты, архитектурные соглашения и критические ограничения для автономных агентов и инженеров, модифицирующих кодовую базу **Тяга** (`tyaga`).

---

## 2. Критические ограничения (НЕ НАРУШАТЬ)

### 2.1. Строгая совместимость с E2E-тестами (`tests/e2e/workout.spec.ts`)
Тест проверяет сценарий входа, редактирования профиля и выхода из аккаунта (строки 120–135):
- Кнопка вызова профиля: `aria-label="Мой профиль"`
- Модальное окно: `title="Мой профиль"`
- Поля формы профиля **ОБЯЗАНЫ** быть доступны сразу при открытии окна (вкладка по умолчанию):
  - Поле `Имя` (`displayName`)
  - Поле `Вес тела, кг` (`bodyMassKg`)
  - Поле `Часовой пояс` (`timeZone`)
- Кнопка сохранения: точный текст `Сохранить профиль`
- Текст статуса после сохранения: `Профиль сохранён`
- Кнопка выхода: точный текст `Выйти из аккаунта`

Любые изменения `AccountProfileForm.tsx` обязаны строго сохранять эти атрибуты и видимость полей.

### 2.2. Запрет на «ИИ-слоп» (AI Slop)
- **Тексты**: никаких роботизированных штампов («Добро пожаловать в потрясающий мир спорта», «Ваше фитнес-путешествие начинается здесь»). Используйте прямой, лаконичный, профессиональный спортивный русский язык: *Жим, Тяга, Присед, Рабочий подход, Тоннаж, 1ПМ, RIR, Разгрузочная неделя, Оверричинг, Напарники*.
- **Дизайн**: никаких ядовитых радужных градиентов и визуального мусора. Тёмная эстетика спортивного зала (`#111512` фон, `#1c241d` карточки, `#cafa64` атлетический лайм), чёткие границы, табличные цифры `font-variant-numeric: tabular-nums`.

## 3. Требования к коду и ООП

1. **Инкапсуляция логики**: вся математика, парсинг, расчёты нагрузок, пирамид и сглаживания должны находиться в классах каталога `src/domain/`.
2. **Типизация**: строгий TypeScript (`strict: true`). Запрещены `any` без крайней необходимости.
3. **Локальные Web API**:
   - Синтез звуков — только через `Web Audio API` (осцилляторы синусоиды/треугольника), никаких сторонних mp3-зависимостей.
   - Тактильная отдача — `navigator.vibrate`.

## 4. Обязательный протокол верификации

Перед завершением любой задачи агент обязан выполнить три команды:

```bash
# 1. Проверка типов TypeScript (0 ошибок)
npx tsc --noEmit

# 2. Прогон полного тестового набора (все тесты должны быть зелеными)
npm test

# 3. Проверка успешности production-сборки Vite и Cloudflare Worker
npm run build
```

Если обнаружена ошибка — немедленно исправьте и перепроверьте.
