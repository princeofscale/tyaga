# Русская локализация упражнений

`wger-ru-names.tsv`: 918 строк `sourceId|русское название|русский алиас`.
Названия и алиасы составлены редакционно с помощью ИИ для конкретных исходных
вариантов. Английские оригиналы и исходные aliases добавляются автоматически.

`wger-ru-instructions-v1.json`: переводы 918 исходных описаний снимка wger через
публичный Google Translate endpoint на этапе подготовки, 07.10.2026. Это
машинный перевод, без гарантии профессиональной проверки техники.
Production-приложение не обращается к переводчику и не отправляет туда данные
пользователей. Сервис перевода не является зависимостью offline pipeline.

Запуск `npm run catalog:localize` объединяет эти входные данные с неизменяемым
`data/wger/catalog-v1.json`. Скрипт проверяет полноту, переносит оригинальный
текст и атрибуцию, локализует оборудование/группы и создаёт отдельные content IDs.
Сейчас получается выпуск `wger-ru-30f116ee54ff61b6`. После публикации новая
правка оформляется новым набором входных данных и отдельным выпуском.

Переводы и адаптации следуют оригинальной CC BY-SA 3.0 / 4.0 либо CC0 лицензии
**каждой** записи. Авторство, source URL и ссылка на лицензию сохранены в output.
MIT лицензия приложения не заменяет лицензии этих данных. Исходный текст можно
прочитать в карточке; неуверенную инструкцию следует сверять с ним.

Алиасы собственного каталога Тяги находятся в `src/data/exercise-aliases.ts`
и не меняют технику, recording spec или мышечную разметку опубликованной версии.
