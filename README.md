# Тяга

Лёгкий журнал тренировок на русском: подходы, вес, повторы, RIR, история и покрытие недельных ориентиров. React 19 + TypeScript + Vite; Cloudflare Worker + D1. Без внешнего AI API, рекламы и аналитических трекеров.

## Что работает

- Запись тренировок: рабочие и разминочные подходы, вес, повторы, RIR, заметки и дата.
- Таймер отдыха переживает reload; черновик показывает реальный статус сохранения. Длительность можно исправить вручную.
- Серверное сохранение, редактирование, повторение фактических подходов и удаление; revision защищает от одновременных изменений.
- Карта 10 зон и 32 анатомические записи: прямые подходы, помощь и стабилизация отдельно, фильтр RIR и выбор недели.
- **«Баланс недели»**: объяснимый план на 20 / 40 / 60 минут; прогноз покрытия ориентиров после выполнения предложенных подходов.
- Вес одной гантели / штанги, явные стороны, помощь в подтягиваниях, идентификатор машины и контекст массы тела.
- Прогресс внутри одной версии и правила записи, e1RM только для разрешённых упражнений, экспорт собственных данных в JSON.
- 31 уточнённый вариант упражнения с русскими/латинскими названиями мышц, ролями, источниками и ограничениями. Версия старого каталога сохраняется в истории.
- Адаптивная версия для телефона, клавиатурная навигация, поддержка уменьшения анимации.
- Опциональные браузерные WebMCP-инструменты для чтения своего баланса и подготовки черновика.

При пустой истории приложение показывает **явно отмеченные примеры**, которые не записываются в базу и не попадают в экспорт. «Мои данные» открывает пустой личный журнал. Завершённые тренировки и цели сохраняются в D1; только незавершённый черновик хранится в браузере.

## Быстрый запуск

Нужен Node.js 22.13+ (проверено на Node.js 24).

```bash
npm ci
npm run build
npx wrangler d1 migrations apply DB --local --config wrangler.jsonc
```

В первом терминале:

```bash
npm run preview:server
```

Во втором:

```bash
npm run dev
```

Открыть `http://localhost:5173`. Сервер разработки использует отдельную локальную базу и тестовую идентичность. **Не разворачивайте `server/local.ts` в интернете.** Production-сборка использует `server/index.ts`, который требует идентичность от доверенной платформы Sites и проверяет владельца каждой записи. При самостоятельном хостинге нужен собственный слой аутентификации; прямому публичному запросу нельзя позволять подставлять `oai-authenticated-user-id`.

## Проверка

```bash
npm run typecheck
npm run build
npm test
```

33 unit/API проверки используют production Worker и настоящую локальную D1: миграции, конфликты, idempotent retry, удаление, owner isolation, timezone/DST, нагрузка/стороны, версии истории, ошибки Storage. CI также запускает 7 браузерных сценариев.

```bash
npx playwright install chromium
npm run test:e2e
```

Playwright сам запускает production preview интерфейса и локальный Worker с отдельной `.wrangler/e2e` базой. Остановите обычные dev-серверы перед запуском, чтобы тесты использовали свою базу. При системном Chromium можно передать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Workflow: [Checks](.github/workflows/checks.yml).

Сборка: `dist/client` — интерфейс; `dist/server/index.js` — Worker. Миграции Drizzle находятся в `drizzle/`. Конфигурация Sites — `.openai/hosting.json`. Продуктовые данные и секреты не находятся в репозитории.

## Отличие от конкурентов

Исследованы [OpenGym](https://github.com/DuarteSantos8/openGym), его [форк с AI Coach](https://github.com/alexpcosta/opengym), [LiftLog](https://github.com/LiamMorrow/LiftLog) и [Workout.lol](https://github.com/workout-lol/workout-lol). Карта мышц сама по себе уже есть у OpenGym. Наша ставка — маленький, быстрый и проверяемый сценарий: **история → пробелы в недельной нагрузке → короткая тренировка → видимый прогноз**. Это направление продукта, а не заявление об отсутствии похожих функций во всех приложениях.

Подробнее: [исследование конкурентов](docs/competitors.md), [методика и версии истории](docs/methodology.md), [источники базы упражнений](docs/exercise-data-sources.md), [ответ на ревью](docs/review-response.md), [проверка](docs/verification.md).

Каталог — редакционная анатомическая разметка с источниками, без независимой сертификации специалистом. Участие мышцы, ЭМГ и гипертрофия не равны. Приложение не вычисляет «100% точные проценты активации», рост или восстановление. Старые неоднозначные веса не угадываются и не складываются с новым внешним объёмом.

Код реализован самостоятельно. Исходный код, медиа и базы упражнений конкурентов не копировались. Компоненты используют React и Lucide с их исходными лицензиями.
