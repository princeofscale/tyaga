# Тяга — дизайн «Сталь»

Интерфейс силового журнала: угольные поверхности, чёткие границы, высокая контрастность и один акцент. Лайм — тема по умолчанию; выбранный в профиле цвет управляет теми же семантическими токенами. На главной и входе нет декоративного арта, рекламных панелей и отдельных рамок для каждого показателя.

## Маршруты

- **Сегодня.** Старт, продолжение черновика или просмотр выполненного по плану — в первом блоке. Там же план с упражнениями и источниками весов. Рядом краткий итог недели; нажатие на нагрузку открывает расшифровку в «Прогрессе». Остальное доступно через «Ещё».
- **Тренировка.** В режиме «В зале» — один подход с крупными полями, прошлый результат и таймер. «Весь список» возвращает таблицу и расширенные настройки. Вес стека и величину помощи можно записать без названия или выбора тренажёра. Данные старых записей сохранены.
- **Программы.** На широком экране неделя в семь колонок, на телефоне — список дней. Текущий день отмечен полосой, записанные тренировки — галочкой и подписью. Через «⋯» можно перенести, пропустить или вернуть отдельную тренировку. В карточках программ видны упражнения и рабочие подходы; готовые варианты — в разделе «Шаблоны».
- **Черновик.** Второе окно показывает тренировку без правок, пока явно не нажать «Продолжить здесь». Законченная офлайн тренировка остаётся в истории и отсылается после восстановления связи.
- **Журнал.** Боковая панель на широких экранах и нижние вкладки на телефонах используют одни и те же кнопки. Вход, история, прогресс, программы, каталог, друзья и окна оформлены в тех же материалах.

## Стили

- Стили консолидированы в `src/styles/` (13 модулей с каскадными слоями `@layer tokens, base, layout, components, screens, utilities` в `src/styles/layers.css`).
- Переходы короткие, без фонового параллакса и бесконечной анимации на главной. `MotionConfig reducedMotion="user"` учитывает системную настройку уменьшения движения.

## Типографика и движение

**Sofia Sans Condensed** — заголовки; **Golos Text** — интерфейс; **JetBrains Mono** — коды и табличные значения. WOFF2 для кириллицы и латиницы лежат в src/assets/fonts вместе с лицензиями SIL OFL. Шрифты отдаются тем же сервером, отдельно выбранные поднаборы подгружаются по символам.

Motion ведёт индикатор между вкладками, показывает направление при смене недели в «Программах», заполняет шкалы тренировки и прорисовывает галочку в момент отметки подхода. Нет зацикленного декора. В режиме уменьшения движения остаются видимое выбранное состояние, готовая галочка и итоговые значения.

## Проверка

~~~sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e:visual
~~~

Визуальный режим (`TYAGA_PLAYWRIGHT_MODE=visual` в `playwright.config.ts`) использует порт 5686 только на loopback. Данные подставляются браузерными фикстурами, поэтому сервер и пользовательская база для этих сценариев не нужны. Кадры: `artifacts/design/` и `artifacts/design-quiet/`.
