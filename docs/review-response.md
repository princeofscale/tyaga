# Исправления по независимому ревью

Релиз 1.1, 7 октября 2026. Присланный отчёт использован как список проверяемых замечаний. Его filecite-ссылки недоступны в этой сессии; код проверен локально, научные и лицензионные источники проверялись отдельно. Уровень проверки каждого научного источника указан в evidence registry.

| Замечание | Результат |
| --- | --- |
| Локальная дата против UTC | IANA timezone записи/профиля и общая календарная функция клиента/сервера; тесты midnight, DST, Sunday/Monday. |
| Last-write-wins | Атомарная revision, 409 с текущей версией, UI сохранения своего черновика/отдельной копии. DELETE также проверяет revision. |
| Ложное обещание сохранения черновика | Постоянное сообщение об ошибке Storage, скачивание локального черновика, сохранение через API остаётся доступным. |
| Неопределённый вес | Версионированные recording specs, per-implement, per-side, помощь отдельным числом, идентификатор машины, отдельный контекст массы тела. |
| Warmup-only | API и интерфейс требуют хотя бы один завершённый рабочий подход. |
| Восемь часов закрытой вкладки в duration | Пауза при скрытии/восстановлении, контрольные точки активного счётчика, ручное исправление минут. |
| e1RM на массе тела / стеке | Eligibility; отключён для bodyweight, помощи, машин и старого неизвестного правила. Версия формулы и правило отображения указаны. |
| Таймер отдыха после reload | Deadline и пауза в draft, одно объявление завершения для screen reader. |
| «Последний вес» | Последний завершённый рабочий подход последней совпадающей серии, timestamps и устойчивое разрешение равенства. Старые неоднозначные значения не копируются в новый per-hand ввод. |
| Повторение сессии | Клонируются фактические подходы, веса, warmup, стороны и версии; fresh IDs, done сбрасывается. |
| Очень грубая разметка мышц | 32 анатомические записи и отдельные роли, 10 простых зон в обзорном интерфейсе. |
| Неопределённые варианты | Отдельные floor bridge / barbell hip thrust, seated / prone leg curl, standing / seated calf; reverse lunge и face-pull+ER определены для новых записей. Старые ID не переопределены. |
| Псевдоточные коэффициенты | Текущая модель без RIR множителей и «0,5 стимула», помощь отдельно, покрытие по прямым подходам. |
| Незаметная смена истории | Каталог 1 заморожен; новые записи несут версии. Пересчёт явно выбирается, веса не меняются; старая арифметика доступна в деталях. |
| Нет воспроизводимой проверки / CI | 33 unit/API проверки и 7 Playwright сценариев, конфигурация отдельной локальной БД, GitHub Actions workflow. |

Новый паттерн retry также фиксирует длительность перед запросом: после server commit и потерянного ответа повтор отправляет прежний payload. Два устройства, конфликт и потеря ответа проверяются в реальном браузере.

## Границы этой версии

**Authentication:** официальный production entrypoint по-прежнему предназначен для доверенного Sites ingress. Он не является JWT/auth сервером; внешний user-id header должен отбрасываться и заменяться платформой. Независимая криптографическая проверка или публичный self-host adapter не добавлены. `server/local.ts` — только разработка. Worker tests проверяют отсутствие identity и owner isolation, но не доказывают фильтрацию заголовков реальным Sites ingress.

**Наука:** 31 описание не имеют независимой сертификации специалистом. Часть источников проверена только по метаданным, и это видно в карточке. Ни EMG, ни журнал не дают точного процента стимула/роста конкретной мышцы.

**Следующие задачи:** импорт Strong/Hevy/FitNotes, пользовательские упражнения, wger staging ingestion, incremental sync и PWA остаются в backlog. Recovery engine, AI Coach и большая медиатека не добавлены. Приложение остаётся небольшим журналом с однозначными числами.
