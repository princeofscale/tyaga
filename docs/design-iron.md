# «IRON» — визуальный слой 2.0 (историческая спецификация)

> Актуальные стили консолидированы в `src/styles/` (13 модулей с явным порядком `@layer` в `src/styles/layers.css`). Компонент `useHeroStage.ts` и файл `steel-plate.webp` удалены. DOM и e2e-контракты сохранены.

## Что переработано

- **Палитра**: графит `#07090a` / `#0f1213`, мел, акцент — тема пользователя
  (`--accent` ставится inline в `lib/theme.ts`). Все оттенки акцента считаются
  через `color-mix(in srgb, var(--accent) …)`, поэтому «Бирюзовый», «Янтарный»
  и остальные темы работают без отдельных правил.
- **Атмосфера**: мягкий свет акцента сверху справа + техническая сетка 96 px
  (`.app-shell::before/::after`, `position: fixed`, `z-index: -1`).
- **Каркас**: боковая панель с микро-типографикой (mono, капс), штрих активного
  пункта, «доска недели» (`.sidebar-rail`) на десктопе; на телефоне — стеклянный
  таббар с подсветкой активного пункта.
- **Герой дня**: тёмная «сцена», крупный узкий заголовок, нумерованный список
  упражнений (CSS-счётчик `::before`), пластина с параллаксом и пятном света.
- **Карточки**: волосяные границы, верхний световой блик, подъём при наведении
  (только для мыши — `@media (hover: none)` его отключает).

## Анимации (Motion)

| Где | Что | Файл |
| --- | --- | --- |
| Переход экрана | `opacity` 0.26 c + пружина `y` | `App.tsx` (`.page-content`) |
| Вход секций | `enter(delay)` — opacity + y, стаггер по дашборду | `App.tsx` |
| Герой | параллакс пластины и пятно света по указателю | `components/motion/useHeroStage.ts` |
| Ячейки недели | стаггер 0.03 c на ячейку | `components/WeeklyActivityBar.tsx` |
| Метр недели | `scaleX` 0 → 1 | `App.tsx` |

Правила, которые нельзя нарушать:

1. **Только `transform` и `opacity`.** Пятно света — круг фиксированного размера,
   двигается через `x/y`; перекраска градиента на каждом кадре не используется.
2. **Никаких бесконечных анимаций на дашборде**: `design.spec.ts` проверяет, что
   `document.getAnimations()` не содержит запущенных `iterations: Infinity`.
3. **`prefers-reduced-motion`**: входы и параллакс выключены (`useReducedMotion`
   → `initial: false`), цветовые и opacity-эффекты остаются.
4. **Никаких layout/layoutId**: приложение работает под `LazyMotion` с
   `domAnimation`, где проекция макета недоступна.

## Жёсткие ограничения из тестов

- `#plan-title` остаётся в гарнитуре `Tyaga Display` (проверяется `design.spec`).
- `html[data-theme-accent]` и inline-переменные темы не перетираются.
- На телефоне `.page-content` держит боковой padding **16 px**: ряды вроде
  `.muscle-chips-row` имеют `margin: 0 -16px` и при 14 px вылезают за экран
  (ловит `workout.spec.ts` при 390 px и 200 % текста).
- `.page-content` должен доходить до `opacity: 1` — не завешивать вход.

## Как проверять визуально

```bash
npm run build
npm run test:e2e:visual
```

Режим `TYAGA_PLAYWRIGHT_MODE=visual` в `playwright.config.ts` поднимает только `vite preview` (воркер и D1 не нужны):
все запросы `/api/**` замоканы внутри спек. Скриншоты: `artifacts/design/`
(базовый набор) и `artifacts/design-quiet/` (окна, живая анимация, 320 px,
история и программы).
