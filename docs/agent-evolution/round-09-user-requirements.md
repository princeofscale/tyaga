## 4. Требования

### R09-REQ01 — комната: правка завершённой тренировки не должна менять статус в комнате
**Что не устраивает.** О1: «Закончил · 1,9 т» → «Готовится · Жим штанги лёжа · 0 т» у напарника и у себя; после «Сохранить» не возвращается; в правке прошлой тренировки висит шапка комнаты («Поделиться», «Выйти», код, строка напарника).
**Что изменить.**
1. Пока человек правит **уже сохранённую** тренировку, строка его участия в комнате не меняется: «Закончил · N т» остаётся; после «Сохранить» N пересчитывается по правке (например, 1 885 → 1 935 кг, «1,9 т»); «Готовится / 0 т» появляется только при начале **новой** тренировки в комнате.
2. В экране правки сохранённой тренировки не показывать шапку комнаты и её кнопки («Поделиться», «Выйти», код, строки напарников); правка — не тренировка в комнате.
3. В строке участника в комнате («Жим штанги лёжа · 3/3 | 1.9 т») десятичный разделитель — запятая, как в остальных местах («1,9 т»).
**Ожидаемый результат.** Поправил опечатку в весе — напарник по-прежнему видит «Закончил», а не «0 т».
**Важность.** Высокая: другому человеку показываются неверные данные.
**Критерии приёмки.**
1. A и B в одной комнате; A: «Жим штанги лёжа» 80 / 82,5 / 82,5 × 5 / 11 / 7, ✓ ×3, «Завершить» → у A и B строка A «**Закончил · 1,9 т**». A: «История» → карточка → «Редактировать» → вес подхода 1 → 90 (итог в правке 1 935 кг). Не позже чем через 15 с у B строка A **остаётся «Закончил · 1,9 т»** — нет «Готовится» и «0 т» (скриншот у B).
2. A: «Сохранить» → у A и B ≤ 15 с «Закончил · 1,9 т» (1 935 кг → «1,9 т»); в «Ленте тренировок» у B карточка A «1,9 т свободных весов» (как сейчас).
3. В экране «Редактировать» сохранённой тренировки у A **нет** «Комната 5HJHZ · 2 участника», «Поделиться», «Выйти» и строки «Анна · Закончил …»; внизу «Сохранить» и «Отмена» работают как сегодня.
4. После правки A нажимает «Начать тренировку» в этой же комнате: у B строка «Игорь · Готовится» → ✓ подходы → «Отдых … · 1/3» → «Закончил» — как сегодня.
5. Подпись участника во время тренировки у обоих («Жим штанги лёжа · 3/3 | 1,9 т» после возврата в комнату) — с запятой; скрипт по тексту комнаты `\d\.\d\s*т` возвращает пусто.
6. Правка прошлой тренировки без комнаты — как сегодня (то же окно без шапки комнаты, «Сохранить» → «Тренировка сохранена»).
7. Тест на политику отправки состояния комнаты при правке сохранённой тренировки; `npx tsc --noEmit`, `npm test`, `npm run build` — без новых падений. Серверная часть не меняется (по журналу воркера: ни одного `PUT /api/friends/live/state` с «idle» и 0 т во время правки).

### R09-REQ02 — «Заменить»: чипы снаряда должны показывать то, что есть в списке «Все снаряды»
**Что не устраивает.** О2: «Гантели», «Штанга», «Блок / Кроссовер», «Тренажёр» → 0, хотя в «Все снаряды» 10 альтернатив с этими метками; чипы 28 px.

**Ожидаемый результат.** Нажал «Гантели» — увидел жимы гантелей.
**Важность.** Средняя: мешает в зале при каждой замене, зато правка локальная.
**Критерии приёмки.**
