**QA-R04-01 — плашка комнаты увеличивает липкую шапку и закрывает подходы (Medium).** `d-room-390-results.json`, `d-room-360-results.json`, `d2-sticky-360-results.json`, `d2-sticky-390-results.json`, `d2-sticky-360-s1-room-scrolled.png`.
Воспроизведение: два аккаунта на cloud-стенде; A: «Друзья» → «Создать комнату» → «Начать тренировку» → добавить «Жим штанги лёжа» (3 подхода), ввести 60 × 8, поставить ✓ у подхода 1 (запускается таймер отдыха); 360×800.
Наблюдение: `.room-badge` находится внутри `.workout-bar` (`position: sticky; top: -137px`). Без комнаты высота шапки 209 px, закреплённая часть 72 px. С комнатой шапка 392 px, закреплённая часть 255 px (32% высоты экрана), плашка занимает 165 px, потому что кнопки «Поделиться» и «Выйти из комнаты» на 360 идут двумя рядами. На 390×844: шапка 199 → 318 px, закреплённая часть 72 → 191 px, плашка 101 px.
Следствия: (а) при прокрутке 0 с комнатой строки подходов 1–3 стоят на y = 710 / 760 / 810 — ниже фиксированного таймера отдыха (верх таймера 699 px), `elementFromPoint` по центру ✓ подхода 1 возвращает кнопку таймера (без комнаты те же ✓ на y = 527 / 577 / 627 и не закрыты); (б) прокрутка до конца: ✓ подходов 1–3 под закреплённой шапкой, `elementFromPoint` возвращает `workout-bar` и `room-badge-actions`; (в) рабочая область между закреплённой шапкой и таймером: 444 px против 627 px без комнаты. Критерий приёмки 4 («на 360×800 плашка не перекрывает таймер отдыха и ✓») выполнен только в статичном положении, e2e инженера меряет его именно так.

### 7. Не проверено

- Реальный телефон, iOS/Android-клавиатура, палец и перчатки; нативный `navigator.share`, буфер обмена на устройстве (в headless «Поделиться» даёт тост «Не удалось скопировать»); звук и вибрация.
- «Применить разгрузку» при активной незавершённой тренировке: инструменты доступны только с «Сегодня», а на экране тренировки навигации нет, поэтому окно с оговоркой про черновик я не открывал. Состояние «Нечего менять» без программ — только по e2e инженера; «Отменить»/баннер при втором устройстве и синхронизация разгрузки между устройствами (разгрузка — флаг устройства по описанию инженера, не проверялось).
- Комната: вход со второго устройства по ссылке-приглашению (проверен вход по коду двух аккаунтов в одном браузере-эмуляторе), закрытие комнаты владельцем, комната вне Chromium, поведение плашки при потере сети.
- Рассылка кода восстановления по почте (в проекте её нет), потеря пароля вместе с кодом (по описанию инженера остаётся неисправимой), перевыпуск кода с двух устройств одновременно (ответ 409 по коду, вживую не гонял).
- Часовой пояс: сохранение несуществующего пояса в интерфейсе, влияние смены пояса на уже записанные даты.
- Экраны, не вошедшие в развёртку 360×800 на горизонтальный скролл: «Резервная копия», «Объём по мышцам», «Анализ техники по видео», «Мои тренажёры», «История → Импорт» в раскрытом состоянии.
- Состав каталога «База» на реальном импорте wger в production (проверена только D1 этого стенда: 918 записей); анализ техники, Apple Health, сторис-карточка.
- Единственный браузер — Chromium (Playwright); Safari/Firefox не запускались. Первый вход и офлайн-запуск без предшествующего онлайн-визита (QA-R03-01 раунда 3) в этом проходе не повторялись.
- Тесты `agent-qa-baseline.spec.ts` и `agent-po-initial.spec.ts` не входят в 12 обязательных файлов и не запускались.
