Что это значит для меня: утром я сверяюсь именно с этой карточкой; «× 0» похоже на сломанный план или на «ничего не делать».

## 4. Требования

### R07-REQ01 — «Сегодня по программе»: правильное «подходы × повторы»
**Что не устраивает.** «3 × 0 · 60 кг» (`11`): повторы показаны нулём, а число подходов считает и разминку.
**Что изменить.** Строка упражнения на карточке плана на «Сегодня» берёт повторы так же, как строка в «Программах» и как сама тренировка: если у упражнения задан диапазон — «3 × 8–12»; если у подходов есть конкретные повторы — «3 × 10»; если повторов нет вообще — число повторов не показывается («3 подх.»), но никогда «0». Число подходов — только рабочие (без разминочных). Вес и подпись «по плану / вес из истории» остаются как есть.
**Ожидаемый результат.** План на карточке «Сегодня» совпадает с тем, что я увижу после «Начать».
**Важность.** Средняя: первый экран дня, ошибка видна всем новым пользователям с программой без «Прошлого».
**Критерии приёмки.**
1. Чистая D1, программа «Верх А»: «Жим лёжа» 3 рабочих подхода, 60 кг, повторы не заданы → карточка не показывает «× 0» (как в тренировке — «3 × 10» или «3 подх.»); с заданным диапазоном 8–12 → «3 × 8–12 · 60 кг».
2. Тот же день с 2 разминочными + 3 рабочими → «3 × …», не «5 × …».
3. Подходы без повторов и диапазона → «3 подх.», в тексте карточки нет «× 0» ни для одного упражнения.
4. После «Начать» в тренировке то же число подходов и повторов, что на карточке (на примере 1–3).
5. Тесты на форматирование строки (диапазон / конкретные / без повторов / с разминкой); в `npm test` и `npm run build` — без новых падений.

### R07-REQ02 — склонение «рабочих подходов»
**Что не устраивает.** «1 рабочих подходов», «21 рабочих подходов» в ленте напарников (`07`) и в «Прогрессе».
**Что изменить.** Склонять по числу везде, где пишется «N рабочих подходов»: 1 → «рабочий подход», 2–4 → «рабочих подхода», 5–20 → «рабочих подходов», 21 → «рабочий подход», 22–24 → «рабочих подхода», 11–14 → «рабочих подходов». Одним помощником (как уже сделано для других слов, если он есть), а не точечными правками.
**Ожидаемый результат.** Лента, день в «Прогрессе» и «Тренировки на связи» читаются по-русски.
**Важность.** Низкая по риску, но видна другим людям.
**Критерии приёмки.**
1. В ленте напарников: 1 → «1 рабочий подход», 21 → «21 рабочий подход», 2 → «2 рабочих подхода», 14 → «14 рабочих подходов», 25 → «25 рабочих подходов».

3. Юнит-тест на 0, 1, 2, 4, 5, 11, 12, 14, 21, 22, 25, 101, 111.
4. `aria-label` календаря активности — тоже склоняется (сейчас «0 рабочих подх…»).

### R07-REQ03 — цели касания в «старых» вкладках: ≥ 44 px

**Ожидаемый результат.** Забытую вчерашнюю тренировку записываю за минуту, видя, на какое число идёт запись.
**Важность.** Низкая-средняя: работает и сейчас, но найти нельзя без подсказки.
**Критерии приёмки.**
1. «История» → «Записать тренировку» → на экране без прокрутки есть дата и доступ к ней (≤ 1 нажатие до выбора даты).

3. Для обычной сегодняшней тренировки шапка не меняется (без новых подписей).
4. Дата по часовому поясу профиля, не по поясу браузера (проверить на `Europe/Saratov` и на другом поясе).
5. Тест на логику (задним числом / сегодня); `npm test` зелёный.

## Ответы на вопросы lead

1. **«67 % подходов» вместо «64 %».** Меня устраивает: в ТЗ «85 %/64 %» — цифры из моей программы на 14 подходов (14 → 9); строка честно показывает то, что считает приложение для выбранной разгрузки, и совпадает с «Программами» там, где подходов много (у A — «64 %», 14 → 9). 3. **Вес и «по плану» из первого рабочего подхода** — подтверждаю: «Верх Б» с разминкой 25 кг показывает «60 кг · вес из истории», не 25.
