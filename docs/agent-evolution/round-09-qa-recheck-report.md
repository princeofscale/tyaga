### 2a. Ключ `tyaga-live-finished:<accountId>` — выход и разные аккаунты (`rc0a.mjs`)

| Шаг | Результат |
|---|---|
| Вход A, «Завершить» | ключ `tyaga-live-finished:<A>` записан (не только в комнате: пишется при любом завершении) |

| Вход B (новый аккаунт) | ключей A нет, чужой id не утекает; после завершения у B свой ключ `…<B>` |
| Сессия B потеряна (cookie), вход A **без** «Выйти» | ключ `tyaga-live-finished:<B>` **остаётся** на устройстве, хотя остальные ключи B (кэш, офлайн-копия) стёрты `purgeOthers` — **QA-R09-10 (Low)**: ключа нет в списке `perAccount` в `src/lib/deviceAccountData.ts` |
