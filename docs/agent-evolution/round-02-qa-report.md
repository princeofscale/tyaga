## Подтверждённые дефекты на `cb96307`

**QA-R02-01 · высокая/блокер · R02-REQ02: частичный импорт без отмены и смешанная замена.** Чистая собственная D1 `.wrangler/agent-evolution-qa-r2-fault-fresh`, локальный Worker `:8898`, Chromium mobile 360×800, подлинный Strong CSV (21 сессия, 175 подходов). На `POST /api/import` первый пишущий пакет из 5 тренировок прошёл (`HTTP 200`, `imported=5`), для второго Playwright network interception вернул тестовый `503` до обращения к серверу: `/api/data` вернул **5 тренировок / 43 подхода**. UI показал «Уже сохранено 5 сессий…»; баннер «Отменить импорт» отсутствовал (`0`). После повторного запуска UI показал «добавлено 16, заменено 5». При следующей повторной загрузке того же файла с ответом «Нет или не знаю» первый пакет записался, второй был прерван `503`: `/api/data` вернул **21 сессию, из них 5 literal/custom и 16 сопоставленных**, то есть единый файл находится в смешанном состоянии. Ни одна из двух операций не атомарна на уровне файла; серверный `D1 batch` ограничен одним пакетом. Шаги, ответы и числа: [`fault-import-results.json`](../../artifacts/agent-evolution/qa/r02-fresh/fault-import-results.json), [`06-fault-import.log`](../../artifacts/agent-evolution/qa/r02-fresh/06-fault-import.log), [`fault-first-import-360.png`](../../artifacts/agent-evolution/qa/r02-fresh/fault-first-import-360.png), [`fault-replace-mixed-360.png`](../../artifacts/agent-evolution/qa/r02-fresh/fault-replace-mixed-360.png). При повторе число сессий в одном запросе API в скрипте было прочитано до завершения клиентской загрузки; баннер сообщает 16+5, а после следующей частичной замены API подтвердил 21. Оценка относится к состояниям **непосредственно после инъецированного отказа**, а не к этому промежуточному моменту.

**QA-R02-02 · высокая/блокер · R02-REQ02: «Отменить импорт» удаляет межустройственную правку.** Чистая D1 `.wrangler/agent-evolution-qa-r2-fresh` на `:8897`, аккаунт A: импортированы 21 тренировка, затем `POST /api/sync/apply` для одной импортированной тренировки (`id=import:…`, `versionAt=2030-01-01T00:00:00.000Z`, `revision=1`) записал заметку `REMOTE-EDIT-QA-DO-NOT-DELETE` и изменённый вес. Ответ 200 `applied:1`, повторный `/api/data` подтвердил новую заметку и **ревизию 1**. После перезагрузки страницы UI «Отменить импорт» → «Убрать 21» удалил **все 21**, в том числе правленную на другом устройстве: `/api/data` 21→0; `/api/sync/changes` содержит `deleted:true` для изменённого id. Так нарушение обещания «те, что ты правил, не трогаем» приведёт к потере пользовательских данных. Полный точный payload/ответы: [`sync-undo-results.json`](../../artifacts/agent-evolution/qa/r02-fresh/sync-undo-results.json); [`07-sync-undo.log`](../../artifacts/agent-evolution/qa/r02-fresh/07-sync-undo.log), [`sync-undo-390.png`](../../artifacts/agent-evolution/qa/r02-fresh/sync-undo-390.png).

**QA-R02-03 · средняя · R02-REQ03: Обзор показывает `0 т`, когда тоннаж неизвестен.** Собственный локальный :8898, Chromium 360×800, после буквального импорта исходного Strong CSV с ответом «Нет или не знаю» (21 сессия / 175 подходов) перешёл `История` → `Сегодня` → `Прогресс` → `Обзор` (4 недели). ## Итог baseline

**Приёмку `cb96307` не рекомендую:** два подтверждённых high/blocker дефекта R02-REQ02 допускают потерю данных; REQ03 имеет средний дефект; REQ04 остаётся PARTIAL по незавершённому cold-failure на живом интерфейсе; REQ07 близко к границе высоты на 360 px. Ни один из положительных результататов не относится к ещё не проверенной инженерной доработке. Для последующих инженеринговых тестов исходные D1-персисты остаются локальными и отдельными; свои процессы 8897/8898 остановлены, 5173/8787 всё время принадлежат e2e-проектному прогону и теперь свободны.

**Что не проверено как отдельный live сценарий:** полный cold/no-preload/offline/Retry на Worker-стенде (только mocked e2e cold fallback, плюс настоящий offline после preload); два реальных аккаунта и межаккаунтная изоляция (локальный entry `server/local.ts` подменяет каждый запрос одним `local-development` owner; отдельный cloud-entry локально не поднимался); редактирование/удаление импортированной и собственной тренировки через UI в привязке к 21 CSV; экспорт JSON через кнопку с проверкой скачанного файла; повторный вход/выход на живом аккаунте; фильтры/повторный undo в обычном UI. Проектные e2e имеют покрытия для части этих функций, но не подставляются вместо live-D1 проверки. Результаты нельзя толковать как PASS для этих незапущенных кейсов.
