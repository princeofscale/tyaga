# Модель нагрузки

Каждый **выполненный рабочий подход** даёт 1 условную единицу основным мышцам и 0,5 вспомогательным. Разминка и невыполненные подходы исключены. У нескольких основных мышц каждая получает 1; это оценка нагрузки, не распределение одного килограмма между мышцами.

Коэффициент усилия:

| RIR | Коэффициент |
| --- | --- |
| 0–3 | 1 |
| 4–5 | 0,75 |
| 6–10 | 0,5 |

Это **продуктовая эвристика**, а не клинически валидированный показатель или точное предсказание гипертрофии. Карта не измеряет силу, размер, технику, усталость или фактическое восстановление. Связи упражнений с мышцами упрощены.

Для каждой мышцы считаются прямой и косвенный объём. Баланс недели — среднее `min(объём / цель, 1)` по десяти группам, выраженное в процентах. Перегрузка одной группы не компенсирует пропуск другой. Исходные цели можно менять под собственную программу; это демонстрационные ориентиры, не индивидуальное назначение.

## Подбор следующей тренировки

1. Берём недостающий объём относительно целей за текущую календарную неделю, с понедельника.
2. Фильтруем упражнения по оборудованию; исключаем упражнения, затрагивающие отмеченные пользователем мышцы прямо или косвенно.
3. Жадно выбираем упражнение с максимальным покрытием оставшихся пробелов, обновляем остаток и повторяем в рамках времени. Упражнение предлагается только один раз.
4. Предлагаем по три подхода. Прогноз предполагает RIR 0–3 и выполнение всех предложенных подходов. Время: 3 минуты подготовки и приблизительно 8 минут на упражнение; фактический темп и отдых могут отличаться.

Причина у каждого упражнения показывает текущую нагрузку целевой мышцы и вклад упражнения. Алгоритм не назначает рабочий вес. Пользователь выбирает вес по своему опыту; предыдущий записанный вес заполняется как удобный ориентир.

## Сила

Расчётный 1ПМ по Эпли: `вес × (1 + повторы / 30)`, для одного повтора — сам вес. Только выполненные рабочие подходы с весом, от 1 до 12 повторений. Это оценка для сравнения одного и того же упражнения, а не призыв проверять максимальный вес.

Объём `вес × повторы` учитывает только записанное внешнее отягощение. Масса тела, движение тренажёрных рычагов и различия оборудования не моделируются. Для односторонних упражнений записываются повторы на одну сторону; суммарный тоннаж здесь не удваивается.
