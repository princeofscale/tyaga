# Проверка релиза 1.3

7 октября 2026. `npm run typecheck`, production build, 44 unit/API проверки и
все 12 Playwright сценариев прошли. После уточнения пустого RIR для времени
повторены 6 затронутых проверок продукта и весь браузерный набор.
Node.js 24.19.0, системный Chromium, production Worker в Miniflare/D1,
production client через Vite preview. Это собственная проверка проекта.

- Все 949 текущих упражнений имеют русское название и aliases. 918 записей wger
  сохраняют оригинальную атрибуцию; новый content ID отличается от архивного.
  Offline локализация воспроизводит `wger-ru-30f116ee54ff61b6`.
- Программа сохраняется в аккаунте, после reload видна в недельном календаре.
  Выполнение 3 × 50 кг × 12 предлагает следующую сессию 52,5 кг × 8;
  незавершённые, разные веса или недостающие подходы не дают прибавку.
- Личное упражнение: создание → поиск по английскому алиасу → избранное →
  reload → 45 секунд → сохранение → reload → изменение до 60 секунд.
  Переименование создаёт новую версию, переносит избранное и сохраняет историю.
- CSV: русское сопоставление, предпросмотр, буквальные веса без подтверждения
  правила, отсутствие RPE/RIR → null, повторный файл добавляет 0, пропускает 1.
  Strong/Hevy/FitNotes, decimal/lb/km/mi, multiline CSV проверены fixtures.
- API: dry run не пишет личную историю; неверный пакет не оставляет половины
  сессии. Повторные запросы не дублируют данные. Другой владелец не получает
  личные определения. JSON backup проверен с программами, своим каталогом
  и избранным; settings восстанавливаются отдельно по выбору.
- Анатомия, клавиатура, 200% текст и mobile 390×844 прошли прежние сценарии.
  Новые программы также не создают горизонтального переполнения. Screenshots:
  `artifacts/programs-v1.3.png`, `programs-mobile-v1.3.png`, `import-v1.3.png`.
- Прежние конфликты, retry после commit, Storage warning, даты/DST, таймеры,
  правила веса и owner isolation также прошли.

При общем прогоне чтение пустого журнала после очистки данных иногда ожидало
до таймаута. В 1.3.1 чтение журнала и настроек объединено в один D1 batch;
добавлена регрессия: создать упражнение на время, добавить в избранное,
записать/удалить сессию и упражнение, пять раз прочитать пустой журнал.
Setup/cleanup используют локальный Worker с закрытием соединения;
пользовательские действия и assertions проходят через client/API proxy.

Новая миграция 0004 добавляет только схему и индексы. Опубликованные каталоги
v1/v2, исходный wger snapshot и прошлые миграции не изменены. Дополнительные
экраны загружаются лениво; main chunk около 89,5 KB gzip, React — 69,2 KB gzip.
Данные wger находятся на сервере, без runtime API переводчика или медиатеки.

Проверки не записывают данные в production аккаунт. Экспертная сертификация
перевода и мышечной разметки не выполнялась. CI и публикация подтверждаются
отдельными статусами GitHub Actions и Sites после отправки исходников.

## Архив: проверка релиза 1.2

7 октября 2026. `npm run typecheck`, `npm run build`, 34 unit/API проверки и все 9 Playwright сценариев прошли. Production preview интерфейса, production Worker в Miniflare/D1, локальный сервер разработки для browser identity, Chromium, Node.js 24.19.0. Это собственная проверка проекта.

Новый пользовательский путь: **Упражнения → wger → локальный импорт в D1 → поиск → карточка и атрибуция → добавление → сохранение → reload → edit**. Все границы подтверждены реальными запросами и чтением базы.

- D1: 918 записей, повторяемый bounded import, поиск с буквальными `%`/`_`, фильтр RU (10 записей), 24 результата на страницу. Сохраняемая definition берётся из базы, подменённая клиентом primary mapping игнорируется. Неизвестный source ID отклоняется.
- История wger переживает reload и edit; рабочие подходы остаются в журнале, непроверенные значения исключены из coverage, тоннажа и e1RM.
- Новый атлас: 35 групп рисунка суммарно в двух видах, выбор мышью / Tab / Enter, переключение видов, связанные упражнения, нормальная загрузка локальной Manrope.
- Экран анатомии: 1440×1080 / 390×844 / 200% текст, без горизонтального переполнения и ошибок JavaScript. Скриншоты сохранены локально в `artifacts/*-v3.png`.
- Прежние сценарии сохранения/конфликта/retry/таймера/Storage/нагрузки также прошли; семантика и owner isolation сохранены.

Библиотека, Query cache и экран анатомии загружаются отдельными chunks. Данные wger находятся в server bundle, не в клиентском JavaScript. Полные notices шрифтов и атласа включены в production assets.

Миграции 0002 / 0003 содержат только ограниченные изменения схемы; seed в миграции не добавлялся. Первое открытие wger создаёт локальную базу порциями с видимым прогрессом, последующие запросы используют готовую release membership.

CI содержит те же проверки; конкретный run проверяется после публикации исходников. Проверка реального production ingress и экспертная научная сертификация по-прежнему отдельно от локальных тестов.

# Архив: проверка релиза 1.1

`npm run typecheck`, `npm run build`, `npm test`: 33 проверки. `npm run test:e2e`: 7 сценариев из `tests/e2e/workout.spec.ts`.

| Граница | Что проверено |

| Два устройства | Два независимых browser contexts редактируют одну сессию; второй не стирает первый, может сохранить отдельную копию |
| Потерянный ответ | В браузере реальный запрос commit выполняется, ответ намеренно обрывается; retry сохраняет одну revision и фиксированную длительность |
| Удаление | Повтор DELETE безопасен; редактирование удалённой сессии не создаёт её снова |
| Browser Storage | Инъекция QuotaExceededError: постоянное предупреждение, скачивание draft, API save доступен |
| Длительность / отдых | Перезагрузка сохраняет минуты и deadline отдыха; восстановление не добавляет закрытые восемь часов; завершение отдыха объявляется |
| Семантика | Штанга, две/одна гантели, unilateral обе/одна сторона, машина, добавленный вес тела, assistance; неподходящие e1RM отключены |
| История | Каталог v1 сохранён; явный пересчёт не меняет records или неизвестный вес; повтор клонирует настоящие подходы |
| Дата | Amsterdam / Los Angeles / Tokyo, local midnight, DST, Sunday/Monday; сервер отклоняет завтра в выбранной зоне |
| Каталог | Уникальные exercise/muscle IDs, существующие source IDs, roles, variant и limitations |
| Основной путь | Создать → заполнить → восстановить → API save → D1 read → edit → export; примеры исключены |
| Адаптивность | 1440×1080, 390×844, 200% текст, карточка анатомии/источников; без горизонтального переполнения или JS ошибок |
| Доверенная identity | Production Worker: anonymous 401, чужой Origin/UUID 403; чужое удаление не затрагивает запись |

Проверки не записывают данные в production аккаунт. Контроль реального Sites ingress, нативного WebMCP в поддерживаемом браузере и экспертная сертификация мышечной разметки не выполнены. Публикация подтверждается статусом Sites отдельно.

## Архив: релиз 1.0

6 октября 2026, Node.js 24.19.0, Chromium, локальный Cloudflare Worker и настоящая D1 в Miniflare.

**Сценарий:** начать тренировку → записать и отметить подход → сохранить через API → прочитать из D1 → открыть в истории и пересчитать нагрузку.

| Граница | Результат | Подтверждение |
| --- | --- | --- |
| Интерфейс | Пройдено | Chromium 1440×1080 и 390×844; ошибок JavaScript нет |
| Черновик | Пройдено | Вес 70 кг и отметка подхода восстановлены после перезагрузки |
| Интерфейс → API | Пройдено | Завершение тренировочного экрана создало запись |
| API → D1 | Пройдено | Запись прочитана повторно после перезагрузки |
| Редактирование | Пройдено | Вес изменён с 70 на 75 кг; в базе одна обновлённая запись |
| Настройки | Пройдено | Цель груди изменена с 10 на 11; новое значение прочитано через API |
| Экспорт | Пройдено | JSON содержит только одну собственную запись, без `demo-*` |
| Удаление | Пройдено | Подтверждённое удаление вернуло пустую историю |
| Планировщик | Пройдено | План на 20 минут содержит не более двух упражнений; ограничения проверены тестами |
| Адаптивность | Пройдено | Нет горизонтальной прокрутки в обзоре и библиотеке на 390px; проверено увеличение текста до 200% |
| Доступ | Пройдено | Production API: анонимному запросу 401, чужому Origin 403, чужой записи 403; чужое удаление не затрагивает запись |

`npm run typecheck`, `npm run build`, `npm test` прошли. **11 тестов**: десять проверок модели и валидации, одна интеграционная проверка production API с D1.

Браузер не предоставляет нативный `document.modelContext`. WebMCP-интеграция защищена проверкой поддержки; её проверка в настоящем поддерживаемом контексте в этой среде недоступна. Обычные функции сайта от неё не зависят.

Проверки проведены локально, а не внутри production-аккаунта. Публикация отдельно проверяется по статусу платформы Sites. Локальная тестовая идентичность не включается в production Worker.
