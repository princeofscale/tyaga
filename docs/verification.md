# Проверка релиза 1.1

7 октября 2026. Node.js 24.19.0, Playwright 1.63.0, системный Chromium, production Worker в Miniflare/D1 и локальный браузерный сценарий. Это собственная воспроизводимая проверка проекта, не независимое заключение аудитора.

`npm run typecheck`, `npm run build`, `npm test`: 33 проверки. `npm run test:e2e`: 7 сценариев из `tests/e2e/workout.spec.ts`.

| Граница | Что проверено |
| --- | --- |
| Миграция | База v1 до добавления revision; payload и неоднозначный вес сохранены буквально, revision=0 |
| Две версии | Два параллельных PUT: один 200, другой 409 с актуальной записью; stale DELETE также 409 |
| Два устройства | Два независимых browser contexts редактируют одну сессию; второй не стирает первый, может сохранить отдельную копию |
| Потерянный ответ | В браузере реальный запрос commit выполняется, ответ намеренно обрывается; retry сохраняет одну revision и фиксированную длительность |
| Удаление | Повтор DELETE безопасен; редактирование удалённой сессии не создаёт её снова |
| Browser Storage | Инъекция QuotaExceededError: постоянное предупреждение, скачивание draft, API save доступен |
| Длительность / отдых | Перезагрузка сохраняет минуты и deadline отдыха; восстановление не добавляет закрытые восемь часов; завершение отдыха объявляется |
| Семантика | Штанга, две/одна гантели, unilateral обе/одна сторона, машина, добавленный вес тела, assistance; неподходящие e1RM отключены |
| История | Каталог v1 сохранён; явный пересчёт не меняет records или неизвестный вес; повтор клонирует настоящие подходы |
| Дата | Amsterdam / Los Angeles / Tokyo, local midnight, DST, Sunday/Monday; сервер отклоняет завтра в выбранной зоне |
| Каталог | Уникальные exercise/muscle IDs, существующие source IDs, roles, variant и limitations |
| Основной путь | Создать → заполнить → восстановить → API save → D1 read → edit → export; примеры исключены |
| Адаптивность | 1440×1080, 390×844, 200% текст, карточка анатомии/источников; без горизонтального переполнения или JS ошибок |
| Доверенная identity | Production Worker: anonymous 401, чужой Origin/UUID 403; чужое удаление не затрагивает запись |

GitHub Actions workflow содержит typecheck, build, unit/API и браузерные проверки. Статус конкретного run нужно смотреть в GitHub Actions; локальный результат не подменяет его.

Проверки не записывают данные в production аккаунт. Контроль реального Sites ingress, нативного WebMCP в поддерживаемом браузере и экспертная сертификация мышечной разметки не выполнены. Публикация подтверждается статусом Sites отдельно.

`npm run typecheck`, `npm run build`, `npm test` прошли. **11 тестов**: десять проверок модели и валидации, одна интеграционная проверка production API с D1.

Браузер не предоставляет нативный `document.modelContext`. WebMCP-интеграция защищена проверкой поддержки; её проверка в настоящем поддерживаемом контексте в этой среде недоступна. Обычные функции сайта от неё не зависят.

Проверки проведены локально, а не внутри production-аккаунта. Публикация отдельно проверяется по статусу платформы Sites. Локальная тестовая идентичность не включается в production Worker.
