# Проверка релиза 1.5

5 ноября 2026. `npm run typecheck`, production build, **64 unit/API проверки**
и **все 14 Playwright сценариев** прошли. Node.js 24.21.0, Chromium из кеша
Playwright, production client через Vite preview и production Worker в
Miniflare/D1. Это собственная проверка проекта, не независимая сертификация.

## Что именно проверено

- `npm run typecheck` — без ошибок; `npm run build` — client и Worker собраны.
- `npm test` — 64 проверки, 0 падений. Новые:
  - программа v2 разложена на пять тренировок с наборами 22 / 29 / 24 / 26 / 25
    подходов, дни понедельник / вторник / четверг / пятница / суббота, диапазоны
    повторений приходят из плана, RIR остаётся неизвестным, а не выдуманным;
  - диапазон повторений конкретного движения перекрывает программный и попадает
    в стартовую тренировку (махи 6 × 12, жим 8–10);
  - разгрузочная неделя наступает на пятой календарной неделе, оставляет по
    одному рабочему подходу, ставит 70% веса и RIR 4, и не появляется на
    четвёртой и шестой неделях;
  - после разгрузки первая рабочая неделя берёт вес до неё, а не 70%;
  - ориентиры недели совпадают с суммами плана программы по зонам;
  - старые шаблоны без цикла и без своих диапазонов работают как раньше;
  - сервер принимает программу v2 с движениями выпуска 3, сохраняет цикл и
    парные диапазоны, отвергает `setFactor` вне границ и не копирует определение
    каталожного движения в каждую запись;
  - `/app-version.json`: запись читается, мусор и HTML-оболочка сайта не
    считаются выпуском, плашка появляется только для более нового versionCode,
    а версия для сравнения берётся из `android/app/build.gradle`.
- `npx playwright test` — 14 сценариев; запускались с
  `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` на Chromium 1248, потому что
  `@playwright/test` в `node_modules` ожидает 1243. Это ограничение среды,
  не проекта.

## Что не проверено

- Установка APK через системный установщик и работа плашки обновления на
  телефоне: для этого нужен телефон.
- Редактор диапазонов повторений на ширине 360 px: разметка проверена только
  в браузере на десктопной ширине.
- Числа недельных ориентиров — это план программы v2, а не измеренная нагрузка;
  приложение по-прежнему не оценивает рост и восстановление.
