## Продуктовая гипотеза

Пользователь с небольшим стажем регулярно тренируется, но не видит, куда уходит недельный объём. Тяга превращает запись в следующий конкретный шаг: выбираешь время и оборудование, получаешь упражнения с причинами и прогнозом изменения баланса. Нет обещаний определить фактическую мышечную слабость, восстановление или гарантировать рост по журналу.

## Первая версия

Релиз 1.0 содержал 26 собственных описаний. В 1.1 — 31 уточнённый вариант, 32 анатомические записи, recording semantics, immutable catalogue versions, optimistic concurrency и покрытие ориентиров по прямым подходам. В 1.3 импорт Strong/Hevy/FitNotes, пользовательские упражнения, избранное и программы уже реализованы.

7 октября отдельно сверены README основного OpenGym на `31c6795b40fb54130192b5016d7dc29e9f457d30`: 1 324 упражнения, per-side reps, импорт, revision/409 и опциональный AI Coach прямо описаны в upstream. Форк не подмешивается к возможностям основного проекта. README также различает AGPL-код и права на сторонний exercise/media content. Это проверка документации, не независимая прогонка OpenGym.

В присланном независимом ревью наш сценарий «остаток недельных ориентиров → бюджет времени → короткая сессия → условный прогноз» выделен среди проверенных возможностей OpenGym. Мы считаем это гипотезой различия workflow на указанных ревизиях, не доказанной уникальностью на всём рынке. Научная достоверность не выводится из muscle map конкурента.

## Продукт 1.3

Недельные routines, starter plans, двойная прогрессия, custom exercises,
избранное и импорт — полезные сценарии, независимо реализованные в Тяге.

Подтверждение наших возможностей — собственные API и браузерные проверки,
а не совпадение названий функций в README конкурента.
