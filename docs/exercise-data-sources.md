# Откуда брать упражнения

Проверка источников: 7 октября 2026. Сейчас в production **собственный каталог из 31 варианта**, без импортированной базы или внешней медиатеки. Метаданные Тяги распространяются по MIT; источники исследований остаются под своими лицензиями. Каталог анатомически подробный, но не объявлен научно сертифицированным.

Практический выбор для следующего расширения: **wger как источник кандидатов, собственная проверенная разметка как production-каталог**. Большая библиотека сама по себе не делает мышечные связи правильными.

## Правило допуска в каталог

`raw source → неизменяемый staging → нормализация → сопоставление вариантов → дедупликация → проверка лицензии → анатомический / научный разбор → отдельный релиз каталога`

Ключ дубля: семейство движения, оборудование, определяющая техника и правило записи нагрузки. Сгибания сидя и лёжа, мост на полу и hip thrust со скамьёй, помощь и добавленное отягощение — разные варианты.

Минимальные поля импортированной записи: `sourceUrl`, `sourceId`, `sourceRevision` или дата, оригинальная лицензия и attribution, язык, вариант, оборудование, правило веса/сторон, роли мышц, evidence IDs, reviewer и статус проверки. Медиа имеют собственный provenance и лицензию. Отсутствующее поле не заполняется догадкой.

Нельзя использовать OpenGym как «научный эталон» или выводить право на его данные/медиа из AGPL-лицензии кода. У [OpenGym NOTICE](https://github.com/DuarteSantos8/openGym/blob/main/NOTICE.md) права на сторонний контент оговариваются отдельно. В Тяге реализованы собственные структуры и стандартный паттерн optimistic concurrency, без переноса исходного кода или датасета OpenGym.

Следующий полезный шаг — независимая проверка текущих 31 варианта специалистом, затем небольшой импорт wger metadata в staging. Ни один из этих источников не обеспечивает «100% мышечного участия» для неизвестной техники конкретного пользователя.
